# Mathar's path recurrences and alternative proofs of Prodinger's enumeration

**Authors:** Haobo Ma, Wenlin Zhang

Using Prodinger's enumeration (arXiv:1912.06930v3, 2020, Theorem 1 and Section 3), we give alternative counting proofs and prove Mathar's eight-term recurrence for floor -2 paths (OEIS A379464, revision 20, second Formula, 29 January 2025, n >= 7) and his six-term recurrence for floor -1 (A379463, revision 16, second Formula, same date, n >= 5). An explicit differential-operator certificate transports the known Raney counts to the exact recurrences. We include every fixed lower floor by a finite polynomial correction, prove the recorded asymptotics, and correct the indexing and tree wording in A127902 and companion formulas in A069271.
